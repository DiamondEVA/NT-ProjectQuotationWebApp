# NT Smart Quotation App (เว็บแอปใบเสนอราคา NT)

ระบบสร้างและออกเอกสารใบเสนอราคา / ใบสั่งซื้อ / ใบยืนยันราคา สำหรับ บริษัท โทรคมนาคมแห่งชาติ จำกัด (มหาชน)

## คุณสมบัติเด่น
- ออกแบบสำหรับพิมพ์เอกสารลงกระดาษ A4 ได้อย่างพอดี
- คำนวณราคารวม, ภาษีมูลค่าเพิ่ม (VAT 7%) อัตโนมัติ
- รองรับการเพิ่ม-ลดรายการอุปกรณ์ และเลือกหมวดหมู่สินค้า NT
- พร้อมใช้งานและ Deploy ได้ง่ายบน Vercel (Static Web App)
